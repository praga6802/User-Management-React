# React + Tailwind CSS – User Management System

A beginner-friendly project built with **React, Vite, and Tailwind CSS** to practice React fundamentals through a simple User Management System.

### Features
- Add and view users
- Update user details
- Delete individual users
- Clear all users

### Tech Stack
- React
- Vite
- Tailwind CSS
- JavaScript (ES6+)

### Concepts Learned
- React `useState` Hook
- Event handling and form management
- Rendering lists using `map()`
- CRUD operations and state management

### Getting Started
```bash
npm install
npm run dev
```
